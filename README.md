# 🎮 X2O League

A modern **Tic-Tac-Toe League** built with **React**, **TypeScript**, **Vite**, and **Firebase**.

Players can sign in with Google, compete against a bot in a **Best-of-3** match, and have their statistics and ranking stored in Firebase Firestore.

---

# ✨ Features

- 🔐 Google Authentication
- 🎮 Best-of-3 Tic-Tac-Toe gameplay
- 🤖 Random-move Bot opponent
- 🏆 Leaderboard
- 📈 Rank Point system

---

# 🛠 Tech Stack

| Layer | Technology | Purpose |
|-------|------------|---------|
| **Frontend** | React 19 + Vite 8 | SPA Framework & Build Tool |
| | TypeScript | Static typing |
| | Tailwind CSS 4 | UI Styling |
| **Backend** | Firebase Authentication | Google Login |
| | Cloud Firestore | Database |

# ⚙️ Installation

```bash

```

# 💻 Development
